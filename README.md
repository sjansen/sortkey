# Fractional Indexing for Go

[![Go Reference](https://pkg.go.dev/badge/github.com/sjansen/sortkey.svg)](https://pkg.go.dev/github.com/sjansen/sortkey)
[![License](https://img.shields.io/github/license/sjansen/sortkey.svg)](https://github.com/sjansen/sortkey/blob/master/LICENSE)

Fractional indexing enables efficient, collaborative list data insertion and reordering.

This module is based on [Implementing Fractional Indexing](https://observablehq.com/@dgreensp/implementing-fractional-indexing)
by [David Greenspan](https://github.com/dgreensp).

See also:
 - [Realtime Editing of Ordered Sequences](https://www.figma.com/blog/realtime-editing-of-ordered-sequences/).
 - [CRDT: Fractional Indexing](https://madebyevan.com/algos/crdt-fractional-indexing/)
